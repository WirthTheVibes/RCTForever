# RollerCoaster Tycoon Forever

<img width="650" height="400" alt="logo" src="https://github.com/user-attachments/assets/22b89047-3620-4e9e-9034-2a1fb4698d8c" />


An AI port of [openRCT2](https://github.com/openrct2/openrct2) from C++ to LUA 5.1 to be played within World of Warcraft Forever and World of Warcraft Midnight. It's really bad. 

# Downloading the addon

RCTForever requires the original files of RollerCoaster Tycoon 2 to play. It can either be purchased through Steam or GOG.com. If you already own the original game and it's expansion packs, you will be able to convert these over to LUA and import into RCTForever.

I'll detail the install process once you have those files, but yea the addon releases will contain no copyrighted content.
